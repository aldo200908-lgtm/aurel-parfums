# AUREL — Maison de Parfum

Experiencia conceptual de perfumería de lujo, inspirada en una galería de fragancias.

HTML, CSS y JavaScript sin dependencias de compilación. Compatible con GitHub Pages desde `main` y la carpeta raíz.

- Carrusel con cinco fragancias, botones, flechas del teclado y gestos táctiles.
- Reproducción automática opcional, pausada al cambiar de pestaña.
- Colección filtrable y fichas de notas olfativas en un diálogo accesible.
- Diseño adaptable y preferencia de movimiento reducido.
- Marca y fragancias conceptuales. No hay pagos ni ventas activas.

Para iniciar localmente: `python3 -m http.server 8000`.
